Geojit Communication Engine – AI-Powered Email Creation Studio

Prompt:

Design a complete, modern, professional internal web application UI called “Geojit Communication Engine” or “Geojit Email Studio”.

This is an AI-powered email creation platform for internal teams at a financial services company. The purpose of the platform is to let users create well-structured, compliant, beautifully designed HTML email communications by simply entering information. The system should then generate 3 email options automatically in Geojit tone and style.

The design must feel:

Very easy to use
Guided, not complex
Professional and trustworthy
Minimal and clean
Suitable for financial services
Highly structured
Brand-consistent
Modern but restrained
Premium internal product quality

The product is not a design tool. It is a smart communication engine. The user should feel that the system is doing the hard work. The UI must reduce anxiety and decision fatigue.

Overall design direction

Use a Geojit-style UI language inspired by the provided brand system:

Primary brand color: Geojit green #07877B
Accent color: warm orange #FBB041
Backgrounds: very light grey / off-white / subtle green tints
Text: dark neutral grey, high readability

Use large enough spacing and font sizes so the app feels effortless.

Product concept

This app helps users create email communications across categories such as:

Research & Advisory
Investor Education
Product & Sales
Service & Transactional
Regulatory & Compliance
Onboarding & Journey

The user should not design the email manually.

The workflow is:

User starts a new communication
User selects communication category
User enters information through a very easy smart form
User can also paste raw content, upload files, or paste URLs
AI generates 3 structured email variants
User reviews and selects one
User sees final preview and HTML output
User can submit for approval or export

The system should appear AI-first, guided, structured, and safe.
